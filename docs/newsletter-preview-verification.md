# メルマガ機能プレビュー検証記録

## 2026-09-14

ローカルのVite開発サーバーとManusの一時公開URLの両方で、`/database/customers?tab=newsletter` が HTTP 200 で応答した。Viteの開発用ホスト許可リストには、全ホストを許可せず、ManusサンドボックスURLのサフィックスだけを追加した。

公開プレビューの初期描画では、顧客一覧の「メルマガ」タブに5種類のテンプレートカード、配信リンク編集欄、既存の会員一覧・下書き作成・履歴画面が同時に表示されることを確認した。確認できたテンプレートは、新規登録・初回案内、期間限定キャンペーン、役立つ情報・季節の提案、会員限定・誕生日特典、お久しぶり・再来店案内である。管理画面はログイン必須のため、継続操作には店舗管理者の認証セッションが必要である。

ユニットテストでは、5種類すべてのテンプレートにHP、SNS、クーポン受取の各リンクが含まれること、未設定リンクが下書き保存前に検出されること、メールHTMLでURLがクリック可能なリンクとなり本文がエスケープされることを確認した。
