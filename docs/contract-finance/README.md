# 艶華OS｜契約利益分配 開発メモ（未リリース）
調査日: 2026-11-24
対象: 艶華のみ（華月・艶月・朧月）。旧店舗は含めない。

## 確認した現状
- SalesDashboard.tsx の既存5タブは維持する。
- SalesMonthlyClosing.tsx は daily_clearances と expenses を店舗条件なしで取得し、monthly_closings を ZENRYOKU_STORE_ID で参照・保存している。
- 既存DBの monthly_closings は旧店舗IDに4件、艶華IDに0件。
- daily_clearances は旧店舗146件、艶華123件。expenses は旧店舗145件、艶華3件（交通費のみ）。
- 朧月は艶華所属ルームとして登録済み。営業開始月と出資受領日は確認できていない。
- PaymentManagement.tsx の既存支払実績は expenses.is_paid 等を利用する。
- 既存の月次利益は、日別精算の売上からキャッシュバックを除外し、給与はバック−諸控除＋交通費＋追加支給。日別清算由来の交通費の expenses 行を再控除しない。

## リリース停止条件
経費の店舗所属が不明な状態で分配額を確定すると過大分配のおそれがある。旧店舗の経費を一括で艶華に移さない。
1. 既存経費・日別精算・月別清算について、営業月別に店舗所属・重複・未計上を照合する。
2. 艶華専用の月次正本を確定できるようにする。既存の全店舗月別清算を破壊しない。
3. 返還予定敷金を物件初期費用から切り分ける。350000円全額の配分は確認後のみ。
4. 借入返済の実績日と元本・利息を既存経費行とリンクし、同じ元本は一度だけ控除する。
5. 契約上の利益分配は会計利益・資金残高と別。会計利益は旧集計を流用して断定しない。
